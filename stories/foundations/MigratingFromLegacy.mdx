## Colour

Colour tokens cover surfaces, text, icons, borders, inputs, and status messaging. Select by semantic intent—not by hue—so your implementation stays stable as palette values evolve.

## Typography

Typography tokens define font family, size, weight, line-height, and fluid scaling. DS uses a fluid responsive model where a single token scales smoothly between viewports using CSS `clamp()`.

### How fluid typography tokens work

Instead of multiple per-viewport tokens, a single `brand.heading.fluid.*` token scales smoothly between the Small (≤768px) and XLarge (≥1440px) viewports. Use the **Specimen viewport** toggle in the table below to preview how each fluid token renders at different screen sizes.

### Font family note

The legacy `fontFamily030` (Inter) maps to DS `fontFamily040`. DS `fontFamily030` is the bold serif family, used for bold editorial tokens only.

### Known gaps

- **Letter spacing** — DS omits this property; remove declarations for now.
- **editorialQuote** — No DS equivalent yet; map to nearest heading token.
- **Display sizes above 3.5rem** — Fluid tokens cap at 3.5rem; use `brand.heading.static.*` for larger sizes.
