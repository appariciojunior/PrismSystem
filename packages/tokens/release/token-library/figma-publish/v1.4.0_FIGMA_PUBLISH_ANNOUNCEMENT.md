# Token Library v1.4.0 Figma Publish Update

Added

- ✨ `text.channel.tertiary` — Tertiary channel text token with 3:1–3.7:1 contrast range across all 14 channel themes (light/dark).
- ✨ `icon.channel.tertiary` — References `text.channel.tertiary` for icon/text parity.
- ✨ `surface.transparent` — Transparent canvas surface for gradient fade effects. All 28 semantic themes.
- ✨ `linkInline.regular` / `linkInline.bold` — Link typography now includes weight variants.
- ✨ `linkStandalone.regular` / `linkStandalone.bold` — Standalone link typography with weight variants.
- ✨ `brand.caption.small` — New compact caption at 12px for tight layouts.
- ✨ `brand.caption.medium` — Standard caption at 14px (replaces flat `brand.caption`).

Removed

- ⚠️ `linkInline` (flat) — Use `linkInline.regular` or `linkInline.bold` instead.
- ⚠️ `linkStandalone` (flat) — Use `linkStandalone.regular` or `linkStandalone.bold` instead.
- ⚠️ `brand.caption` (flat) — Use `brand.caption.medium` or `brand.caption.small` instead.

Updated

- 🎨 `text.channel.primary` — Contrast-optimized ramp references with 2-step hierarchy gaps across all channel themes.
- 🎨 `text.channel.secondary` — Contrast-optimized ramp references (max 5.75:1) with 2-step gap from tertiary.
- 🎨 `flag.callout.text` (dark mode) — Now references `{text.primary}` for proper semantic aliasing.
- 🎨 `flag.callout.icon` (dark mode) — Now references `{flag.callout.text}` to match light mode pattern.

Migration

| Before         | After                                                     |
| -------------- | --------------------------------------------------------- |
| linkInline     | linkInline.regular or linkInline.bold                     |
| linkStandalone | linkStandalone.regular or linkStandalone.bold             |
| brand.caption  | brand.caption.medium (14px) or brand.caption.small (12px) |
