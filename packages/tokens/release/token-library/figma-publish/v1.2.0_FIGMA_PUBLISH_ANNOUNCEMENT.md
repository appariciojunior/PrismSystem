# Token Library v1.2.0 Figma Publish Update

Added

- ✨ Added `accent.blue` and `accent.red` with full 20-step ramps in the variable picker.
- ✨ Added static contrast tokens: `surface.static.light`, `surface.static.dark`, `text.static.light`, and `text.static.dark`.

Removed

- ⚠️ Removed inverse semantic tokens from published themes; use dark mode or static tokens instead.
- ⚠️ Removed `spacing.fluid.*` from published viewport sets; use `spacing.static.*` instead.

Updated

- 🎨 Static dark tokens now reference neutral ramp values directly for stable contrast.
