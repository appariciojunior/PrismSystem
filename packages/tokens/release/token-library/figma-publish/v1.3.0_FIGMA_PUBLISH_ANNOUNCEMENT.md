# Token Library v1.3.0 Figma Publish Update

Added

- ✨ Added `ramp.overlay.light` (white alpha progression, 50-1000) to both light and dark brand palettes.
- ✨ Added inverse semantic anchors across all light and dark semantic themes:
  - `surface.inverse`
  - `text.inverse`
  - `icon.inverse`

Removed

- ⚠️ Removed `feedback` semantic groups from all semantic themes and replaced them with `messaging` groups.

Updated

- 🎨 Overlay ramp set is now paired in both modes with `overlay.dark` and `overlay.light`, improving scrim and contrast-option selection in the variable picker.
- 🎨 Dark mode messaging ramps (`info`, `error`, `warning`, `success`) rebalanced across all 20 steps — start (step 50) is now ~14-15% lightness and end (step 1000) is now ~86-88% lightness, replacing the previous near-black starts and muted ends.
- 🎨 Rolled out `messaging` semantic parity from core to all semantic themes by mode.
- 📝 Added clear descriptions for newly introduced inverse semantic tokens.

Migration

- 📐 Replace any `feedback.*` usage with `messaging.*`.
