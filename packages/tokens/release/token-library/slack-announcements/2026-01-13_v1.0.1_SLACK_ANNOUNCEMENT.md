# Token Library v1.0.1 Release Update

Figma: [Token Library - Design System](https://www.figma.com/design/YOUR-FIGMA-FILE-KEY/Token-Library---Design-System?node-id=0-1&t=5qrVz2tRTsjCKEdo-1)

## Added

- New `overlay` ramp for enhanced light overlay control.
- Directional shadow tokens: `up` grouping for bottom-aligned elements (sticky footers, bottom sheets) and `down` grouping for top-aligned elements (headers, dropdowns, modals).
- `active` token grouping with `primary` and `secondary` hierarchy for fill, text, and border.
- `static` token groupings under surface, text, and border for mode-independent colours.

## Removed

- `selected` token grouping — replaced by `active` with `primary` and `secondary` hierarchy.

## Updated

- Channel base colours corrected to match brand, with updated ramps.
- `interactive.secondary.text` updated to `neutral.800` reference for improved contrast and readability.
- Variable scoping: Figma variable picker updated to surface only domain-relevant tokens for each edit context.

How to attach or update the Token Library in Figma:
If you already have the Token Library attached, just click Update.

1. Open your Figma file.
2. Open Assets.
3. Click Libraries.
4. Search for Token Library - Design System.
5. Turn it on or click Update.
