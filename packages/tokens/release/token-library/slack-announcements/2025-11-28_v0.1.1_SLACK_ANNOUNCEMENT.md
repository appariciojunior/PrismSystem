# Token Library v0.1.1 Release Update

Figma: [Token Library - Design System](https://www.figma.com/design/YOUR-FIGMA-FILE-KEY/Token-Library---Design-System?node-id=0-1&t=5qrVz2tRTsjCKEdo-1)

## Added

- 15 Display typography styles for presentations and Figma Slides.
- Spacing documentation with usage examples.
- Grid system (BETA) with responsive columns, gutters, and margins.
- Copy-paste templates for faster Figma workflow.

## Removed

- `base.black` and `base.white` removed from the brand grouping — pure white (`#FFF`) and black (`#000`) are now in the neutral ramp.

## Updated

- On-accent tokens now have hierarchy: Surfaces (`Strong` and `Subtle`) and Text/icons/borders (`Primary` and `Secondary`).
- Spacing scale renamed from T-shirt sizes to numeric names (`sm` → `200`, `md` → `300`, etc.).
- Collection order: Semantic tokens now appear first in Figma.
- Variable scopes updated for smoother design workflow.
- Responsive typography scales available across all screen sizes.

How to attach or update the Token Library in Figma:
If you already have the Token Library attached, just click Update.

1. Open your Figma file.
2. Open Assets.
3. Click Libraries.
4. Search for Token Library - Design System.
5. Turn it on or click Update.
