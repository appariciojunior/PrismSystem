# Token Library v1.3.0 Release Update

Figma: [Token Library - Design System](https://www.figma.com/design/YOUR-FIGMA-FILE-KEY/Token-Library---Design-System?node-id=0-1&t=5qrVz2tRTsjCKEdo-1)

## Added

- Added `ramp.overlay.light` as a white alpha progression (steps 50-1000) in `light/ brand` and `dark/ brand` palettes.
- Added inverse semantic anchors across all light and dark semantic themes:
  - `surface.inverse`
  - `text.inverse`
  - `icon.inverse`

## Removed

- Removed `feedback` semantic groups from all semantic theme sets:
  - `feedback.fill.*`
  - `feedback.text.*`
  - `feedback.border.*`
  - `feedback.icon.*`

## Updated

- Rebalanced dark mode messaging ramps (`ramp.messaging.info`, `error`, `warning`, `success`) across all 20 steps. Step 50 is now ~14-15% lightness (up from ~4-6%) and step 1000 is now ~86-88% lightness (up from ~68-79%), giving a more usable range of contrast in dark theme.
- Updated palette coverage so both modes now include paired overlay ramps (`overlay.dark` and `overlay.light`) for variable selection.
- Rolled out `messaging` semantic groups from core by mode parity to all semantic themes.
- Added usage descriptions for newly introduced inverse semantic tokens.

## Breaking Changes

- Migrate all token usage from `feedback.*` to `messaging.*`.

How to attach or update the Token Library in Figma:
If you already have the Token Library attached, click Update.

1. Open your Figma file.
2. Open Assets.
3. Click Libraries.
4. Search for Token Library - Design System.
5. Turn it on or click Update.
