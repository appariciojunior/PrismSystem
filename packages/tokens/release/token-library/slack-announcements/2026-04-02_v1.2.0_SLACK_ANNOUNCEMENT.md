# Token Library v1.2.0 Release Update

Figma: [Token Library - Design System](https://www.figma.com/design/YOUR-FIGMA-FILE-KEY/Token-Library---Design-System?node-id=0-1&t=5qrVz2tRTsjCKEdo-1)

## Added

- Added `accent.blue` and `accent.red` with full 20-step palette ramps in the Token Library.
- Added `surface.static.light`, `surface.static.dark`, `text.static.light`, and `text.static.dark` for fixed-contrast use cases across themes.

## Removed

- Removed `text.inverse`, `icon.inverse`, and `border.inverse` semantic tokens from published themes.
- Removed `spacing.fluid.*` values from published viewport sets; use `spacing.static.*` in Figma layouts instead.

## Updated

- Updated `surface.static.dark` and `text.static.dark` to reference neutral ramp values directly for stable contrast.

How to attach or update the Token Library in Figma:
If you already have the Token Library attached, just click Update.

1. Open your Figma file.
2. Open Assets.
3. Click Libraries.
4. Search for Token Library - Design System.
5. Turn it on or click Update.
