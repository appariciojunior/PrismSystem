## Updated

- Renamed `text.on-accent.*`, `icon.on-accent.*`, and `border.on-accent.*` tokens to `text.inverse.*`, `icon.inverse.*`, and `border.inverse.*` across all 28 semantic themes (14 themes × light/dark).
- Refined `text.inverse.secondary` value to `neutral.500` for improved visual differentiation while maintaining WCAG AA contrast.

How to attach or update the Token Library in Figma:
If you already have the Token Library attached, just click Update.

1. Open your Figma file.
2. Open Assets.
3. Click Libraries.
4. Search for Token Library - Design System.
5. Turn it on or click Update.
