# Token Library v1.1.0 Release Update

Figma: [Token Library - Design System](https://www.figma.com/design/YOUR-FIGMA-FILE-KEY/Token-Library---Design-System?node-id=0-1&t=5qrVz2tRTsjCKEdo-1)

## Added

- Chip, Flag, and Label component tokens fully connected across all 14 themes, light and dark mode.
- Channel surface tokens expanded from 3 stops to 6: `50`, `100`, `200`, `300`, `400`, `500`. Old equivalents: `low` → `50`, `mid` → `200`, `high` → `500`.
- Two static channel shade tokens that do not flip with dark mode — for branded badges that must hold a fixed channel colour regardless of mode.
- Border radius tokens: `2px`, `4px`, `6px`, and `8px`.
- Compact paragraph typography sizes for captions, metadata, and dense UI.
- Link typography in two variants: sans-serif bold for UI and navigation, serif for editorial body text.
- Link icon token states: hover and pressed.

## Removed

- None.

## Updated

- Interactive tokens overhauled: buttons, links, inputs, and tags aligned and consistent across every theme.
- Font family: UI text now correctly renders in Inter.
- Variable scoping: Figma variable picker now shows only relevant tokens for the current edit context.
- Inverse tokens deprecated — will be removed in the next release. Switch to using dark mode on the component directly.

How to attach or update the Token Library in Figma:
If you already have the Token Library attached, just click Update.

1. Open your Figma file.
2. Open Assets.
3. Click Libraries.
4. Search for Token Library - Design System.
5. Turn it on or click Update.
