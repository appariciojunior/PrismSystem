# Token Library v1.0.0 Release Update

Figma: [Token Library - Design System](https://www.figma.com/design/YOUR-FIGMA-FILE-KEY/Token-Library---Design-System?node-id=0-1&t=5qrVz2tRTsjCKEdo-1)

## Added

- Colour ramps expanded from 10 to 20 steps; base brand colour positioned at step `700` (light mode) and step `500` (dark mode).
- Semantic token guidance for typography and colour.

## Removed

- None.

## Updated

- Light mode cream ramp (`brand.digital.cream`) updated to match the dark mode ramp visually.
- Non-accessible semantic colours updated to meet WCAG 2.1 AA compliance across all colour tokens.
- `tag` semantic colour grouping unified under a single Tag collection with dedicated properties for fill, border, text, and text-only variants.
- Brand/Caption line height updated from 112.5% to 150%.
- `utility.heading` line height updated from 112.5% to 125% for better visual hierarchy.
- Brand/Standfirst/Large font size updated from 20px to 22px across all viewports.
- `utility.button` text styles updated to Medium font weight (from Regular).
- Fluid spacing ramp updated to 15 steps with smaller, even-number increments.
- Grid in large viewport updated from 12 to 10 columns.
- Variable order in Figma: Theme (semantic tokens) now appears first, followed by Mode (colour ramps).
- **Breaking:** Colour ramp steps renumbered (10 → 20) — tokens referencing steps like `neutral.300` or `neutral.700` have shifted lightness values. Audit designs and relink to the new equivalent steps.
- **Breaking:** Semantic token paths and groupings reorganized for consistency. Review the Token Library in Figma and update token references in your designs.

How to attach or update the Token Library in Figma:
If you already have the Token Library attached, just click Update.

1. Open your Figma file.
2. Open Assets.
3. Click Libraries.
4. Search for Token Library - Design System.
5. Turn it on or click Update.
