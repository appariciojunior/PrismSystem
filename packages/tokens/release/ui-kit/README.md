# UI Kit — Release Notes

This folder preserves historical UI Kit release files.

The canonical release workflow now lives at `packages/tokens/release/README.md`, and new release authoring should start from `packages/tokens/release/changelog.md`.

The UI Kit houses the component library — built on top of the Token Library. Each component is individually versioned and published as part of a UI Kit release.
