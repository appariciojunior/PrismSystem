# UI Kit Release Update - 2026-03-20

Figma: [UI Kit - Design System](https://www.figma.com/design/hcCXq9ObSEBdXtwROtBSNc/UI-Kit---Web---Design-System?node-id=0-1&t=JWSsH8Z73VTYIGbT-1)

Component versions in this release: Flag 2.0.0, Button 1.2.0, IconButton 1.1.0, Divider 1.1.0

## Added

- Added `xlarge` as a published size for IconButton and Button.

## Removed

- Removed Flag intent `channel` from Figma variants, React props, and Storybook controls. Migrate to `secondary` or `callout` based on editorial meaning.

## Updated

- Button and IconButton now use the canonical size scale: `small` 40, `medium` 48, `large` 56, `xlarge` 64. Review layout spacing if your designs used the previous sizing.
- Divider lines are now lighter: horizontal dividers use `border/secondary`, vertical dividers use `border/tertiary`.

How to attach or update the UI Kit library in Figma:
If you already have the UI Kit library attached, just click Update.

1. Open your Figma file.
2. Open Assets.
3. Click Libraries.
4. Search for UI Kit - Design System.
5. Turn it on or click Update.
