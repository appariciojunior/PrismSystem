# Tooltip Changelog

Full component changelog for docs and Storybook. Figma specs should remain design-change focused.

Date Published: `2026-04-17`

| Version | Date         | Entry                                                                                                                                                                                                                                                                                     |
| ------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `1.0.0` | `2026-04-17` | `UPDATED` Reframed Tooltip within the messaging framework as the lowest-criticality tier: no intent system, control-labelling scope only, with explicit positioning against Banner, Inline Message, and Toast.                                                                            |
| `1.0.0` | `2026-04-17` | `ADDED` Initial Tooltip specification aligned to the live Figma property model (`direction`, `icon`, `label`). Direction values documented as text equivalents (`up`, `down`, `up-left`, `up-right`, `down-left`, `down-right`) replacing arrow unicode characters for code friendliness. |
