Step 01 · Start here

Read the Design DNA.

The foundation every agent loads first. Brand, tokens, voice, motion. Ten minutes to read, gives every later output its grounding.

The DNA captures who your brand is in skill form. It is short enough to read in one sitting and acts as the preamble every other skill loads before producing anything. If a finding ever feels generic, it is because this file hasn't loaded.

Download the DNA
Voice

British English, plain English, active voice. No em dashes.

Colour

Accent tiers built on a neutral core. Themed at the token layer, never on a component.

Tokens

Foundation → Palette → Semantic. Components consume semantic only.

Motion

Fast, calm easings, reduced motion by default. No spring physics.
