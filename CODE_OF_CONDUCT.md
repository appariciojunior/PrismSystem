# Code of Conduct

## Our pledge

We want participation in this project to be a harassment-free experience for everyone, regardless of background or identity.

## Our standards

Examples of behaviour that helps: being respectful and considerate, welcoming newcomers, giving and accepting constructive feedback gracefully, and focusing on what is best for the project.

Examples of unacceptable behaviour: harassment, insulting or derogatory comments, personal or political attacks, publishing others' private information, and any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers are responsible for clarifying standards and may remove, edit or reject contributions that do not align with this Code of Conduct. To report a concern, use the repository's private security/contact channel.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
